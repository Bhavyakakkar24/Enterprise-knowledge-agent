Workflow

How Nexus Works

A deterministic, four-step custom agent loop designed for high precision and zero hallucinations.

01

Ask a Question

Employees submit natural language inquiries regarding leave rules, expense thresholds, IT security, or codes of conduct.

02

Agent Tool Decision

The custom agent inspects query intent and decides whether to invoke search_company_documents or answer general knowledge directly.

03

Azure Hybrid Retrieval

Azure AI Search performs hybrid BM25 + dense vector similarity with Reciprocal Rank Fusion to fetch the top 4 exact policy passages.

04

Grounded Synthesis

Azure OpenAI synthesizes a clear, accurate answer with collapsible references to specific PDF documents, chunk IDs, and page numbers.

Capabilities

Engineered for Enterprise Accuracy

Key capabilities that distinguish Nexus from ungrounded consumer chatbots.

Grounded Answers

All policy responses are strictly constrained to indexed corporate documents, preventing model hallucination.

Source Citations

Every response includes verifiable citations indicating the exact PDF filename, chunk identifier, and source page number.

Multi-turn Conversations

Ask follow-up questions naturally. Client-side memory maintains conversation context across multiple exchanges.

Safe "Not Found" Handling

When an internal document does not cover a topic, Nexus transparently admits the gap instead of fabricating rules.

Hybrid Search (BM25 + Vector)

Combines exact keyword matching for policy codes and numeric limits with 1536-dimensional semantic vector search.

System Design

End-to-End Architecture

High-performance RAG pipeline bridging browser clients, Flask API, and Azure cloud services.

1. Client Layer

Minimalist chat interface with client-side conversation memory and typing feedback.

2. Flask Gateway

Secured with Microsoft Entra ID OAuth 2.0 and strict email allow-list enforcement.

3. Agent Reasoning

Autonomously inspects question intent and orchestrates grounded document searches.

4. Azure AI Cloud

Hybrid RRF retrieval from indexed policy chunks and synthesis via Foundry chat models.
